에셋 작업실 사용 안내

  1. USD 결과 가져오기

    플랫폼이 생성한 기존 에셋을 라이브러리로 가져옵니다. 원본 파일은 변경하지 않습니다.

  2. 참조 이미지와 3D 확인

    앞·옆·뒤·아래를 확인하세요. 단색 보기에서는 형상이 잘 보입니다. 과거 결과에는 당시 구도·모델이 적용되어 있습니다.

  3. 필요한 단계만 다시 생성

    외형·구도는 이미지 후보 생성, 입체 형상은 같은 이미지로 3D 생성을 사용하세요. 올린 이미지의 포즈가 자동으로 바뀌지는 않습니다.

  4. 선택 완료 후 내려받기

    버전마다 선택 완료 표시를 남길 수 있습니다. ZIP에는 GLB·참조 이미지·생성 기록이 들어갑니다. 실제 작업 툴에서 크기·재질을 확인하세요.
